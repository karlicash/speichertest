# Speicher-Test (Wegwerf-Werkzeug)

Messwerkzeug für einen Browser-Speichertest eines privaten Lernprojekts:
Die Seite legt auf Knopfdruck lokale Testdaten im eigenen Browser ab und zeigt an,
was sie beim Öffnen vorfindet. Sie lädt nichts nach und sendet nichts.

Das Original liegt im privaten Projekt-Repository; dieses Repository ist nur die
Auslieferung und wird nach Abschluss des Tests gelöscht.
